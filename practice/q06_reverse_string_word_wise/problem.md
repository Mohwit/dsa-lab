# Q6. Reverse String Word Wise

- **LeetCode:** <https://leetcode.com/problems/reverse-words-in-a-string/> (#151, Medium)
- **Note:** LeetCode version also asks you to trim extra spaces between/around words.

## Problem

Reverse the given string word-wise. The last word should come first, the
second-last word second, and so on. Individual words stay as they are.

## Constraints

```text
0 <= |S| <= 10^5   (|S| = length of string S)
```

## Sample Input 1

```text
Welcome to Coding Ninjas
```

## Sample Output 1

```text
Ninjas Coding to Welcome
```

## Sample Input 2

```text
Always indent your code
```

## Sample Output 2

```text
code your indent Always
```
