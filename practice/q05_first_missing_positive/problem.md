# Q5. First Missing Positive

- **LeetCode:** <https://leetcode.com/problems/first-missing-positive/> (#41, Hard)

## Problem

You are given an array ARR of N integers. Find the first missing positive
integer in LINEAR time and CONSTANT space, i.e. the lowest positive integer
that does not exist in the array. The array can contain negative numbers.

## Example

```text
Input:  [3, 4, -1, 1]
Output: 2   (smallest positive number missing from the array)
```

## Sample Input 1

```text
1
5
3 2 -6 1 0
```

## Sample Output 1

```text
4

Explanation:
  1, 2 and 3 are present; 4 is missing, so the answer is 4.
```

## Sample Input 2

```text
1
5
0 1 2 3 4
```

## Sample Output 2

```text
5
```
