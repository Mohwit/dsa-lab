1. A number is a row of switches

Inside the computer, every whole number is stored as a row of switches. Each switch is off (0) or on (1).

The rightmost switch is worth 1. Each switch to its left is worth double: 2, 4, 8, 16 and so on. The number is the sum of the switches that are on.

Analogy: a row of light switches. Picture eight light switches on a wall, each with a price tag: 128, 64, 32, 16, 8, 4, 2, 1. Turn some on and add up their tags. That total is the number. Bit tricks are ways to flip many switches with one hand.

Race: count the switches that are on

Take n = 44, which is 00101100. How many switches are on? There are two ways to find out. Step through both.

Fast: switch off one 1 per step. n & (n - 1) turns off the lowest 1. Count the steps until nothing is left.

Slow: check every position. Look at all 32 positions one by one, even the many that are 0.

Rule to rememberThink of a number as its switches. Most bit tricks treat each column of switches on its own, with no carrying between columns, which is why they are so cheap.

2. The words and the six operators

A bit is one switch. Writing a number as its bits is writing it in binary. A set bit is a bit that is 1. Bit 0 is the rightmost one, the least significant bit.

OperatorNamePer columnExample (12 and 10)
a & bAND1 only if both are 11100 & 1010 = 1000 (8)
a | bOR1 if either is 11100 | 1010 = 1110 (14)
a ^ bXOR1 if they differ1100 ^ 1010 = 0110 (6)
~aNOTflip every bitin Python ~5 = -6 (see the traps)
a << kleft shiftslide left k places1 << 3 = 1000 (8)
a >> kright shiftslide right, drop the bits that fall off12 >> 2 = 0011 (3)

A mask is a number used as a stencil, such as 1 << i to pick out bit i. Negative numbers use two's complement: -1 in 32 bits is thirty-two 1s.

Try it: AND, OR and XOR, one column at a time

Pick two numbers from 0 to 255 and an operator. Step through: every column is decided by its own two switches. Nothing carries.

Three XOR facts to know coldx ^ x = 0 (a pair cancels). x ^ 0 = x (0 changes nothing). Order does not matter, so a ^ b ^ a = b.

3. Mental map: from a blank page to working code

  1. Signal"Every item appears twice except one", "O(1) extra memory", "count the 1 bits", "power of two", "without using + or -", "reverse the bits", "all subsets of up to 20 items", or a stated 32-bit range.
  2. AskWrite a tiny example in binary on paper. What happens in one column of switches? Do pairs cancel? Do I need to read, write or count single bits?
  3. Pick the variantEach variant has its own tell-tale sign.
    • pairs cancel, one left overXOR fold: acc ^= x over everything (Single Number, Missing Number).
    • count or test the 1sn &= n - 1 drops the lowest 1; n & (n - 1) == 0 tests a power of two.
    • read or write bit imasks and shifts: get, set, clear, toggle (Reverse Bits).
    • add without +, fixed widthXOR is the sum, AND shifted left is the carry; mask to 32 bits in Python.
    • answers for all of 0..nreuse a smaller answer: bits[i] = bits[i >> 1] + (i & 1).
    • every subset of a small setloop mask over range(1 << n); bit i says "item i is in".
  4. InvariantXOR fold: acc is the XOR of everything seen so far, so every finished pair has already cancelled. Drop loop: each step removes exactly one 1, so the step count equals the number of 1s.
  5. StepsStart with the identity (0 for XOR and OR, all-ones for AND). Loop over the items (fold), over the set bits (drop), or over exactly 32 positions (reverse, scan). Apply one operator per step. If negatives can appear, mask with 0xFFFFFFFF first and convert back at the end.
  6. CheckNegative input in Python (endless 1s on the left). ~x is -x - 1, not "flip 32 bits". A reverse loop that stops when n hits 0 loses the leading zeros. Precedence is different in C and Java: add brackets.

4. Templates

Template A: read and write one bit

Four one-liners. i is the position, counted from the right, starting at 0.

CodeWhat it means
(x >> i) & 1Get bit i: slide it to the right end, then keep only that switch.
x | (1 << i)Set bit i: OR with a stencil that has one 1. Other bits stay.
x & ~(1 << i)Clear bit i: the stencil is all 1s except a 0 at i. AND keeps everything else.
x ^ (1 << i)Toggle bit i: XOR with 1 flips, XOR with 0 keeps.
x & -xThe lowest set bit on its own (a common helper).
 
# == 4. Templates (x = 10 = 00001010) ==
get bit 1:    (x >> 1) & 1   = 1
set bit 0:    x | (1 << 0)   = 11 (00001011)
clear bit 3:  x & ~(1 << 3)  = 2 (00000010)
toggle bit 2: x ^ (1 << 2)   = 14 (00001110)
lowest set bit of 12: 12 & -12 = 4

Template B: XOR fold, pairs cancel

Every value appears twice except one. XOR everything together: each pair cancels to 0, and the single survives. Compare it with counting in a dict on [2, 7, 4, 7, 2].

CodeWhat it means
def single_number(nums):Find the value with no partner.
acc = 0All switches off. x ^ 0 = x, so 0 is a safe start.
for x in nums:One pass, O(n).
acc ^= xFlip the switches where x has a 1. A second copy of x flips them back.
return accOnly the single is left. Memory used: one number.

Pattern: XOR fold. Watch the 7s and the 2s flip their switches back.

Slow on memory: count in a dict. Tally every value, then look for a count of 1.

Template D: add with no plus sign (32-bit)

XOR adds each column but forgets carries. AND finds the columns where both are 1, which is where a carry is born; shift it left one column and add again. Step through 5 + 7.

measure.py: 5 + 7 = 12 in 3 rounds, -2 + -3 = -5 in 2 rounds, -1 + 1 = 0 in 32 rounds. The mask and the last line are what make negatives work in Python (trap 3).

Rule to rememberPick the operator by the column rule you need: XOR to cancel or flip, AND to test or keep, OR to switch on, shifts to move to a position.

5. Spot the pattern: are bits the trick here?

Read each made-up task. Decide yes or no, name the variant, then reveal.

A. Sensors report in pairs: every sensor ID shows up exactly twice, except one broken sensor that reported once. Find it with O(1) extra memory.

Yes: XOR fold. Signals: "twice except one" and O(1) memory. The pairs cancel, the broken sensor remains.

B. A warehouse only accepts box counts that are a power of two. Check a count fast.

Yes: drop the lowest 1. A power of two has exactly one 1, so n > 0 and n & (n - 1) == 0.

C. A log holds thousands of words. Report the word that appears most often.

No, not this pattern. It says "count", but the counts can be anything, and nothing cancels in pairs. This is a Counter job from arrays and hashing.

D. A pizza shop has 12 toppings. List every possible combination of toppings.

Yes: subset masks (backtracking also works). Loop mask over range(1 << 12), which is 4096 masks; bit i on means topping i is in.

E. Does a number read the same forwards and backwards when written in normal digits, like 1221?

No, not this pattern. It is about decimal digits, not switches. Peel digits with % 10 and // 10 (math pattern).

F. Every value appears three times, except one that appears once. Find the single one.

Yes, but plain XOR fails. Three copies do not cancel. On [5, 5, 5, 3] plain XOR gives 6. Count the 1s in each column and keep the count mod 3: that gives 3, the right answer (measure.py).

Trigger signalsPairs that cancel, O(1) memory with a "twice" promise, counting or testing 1 bits, powers of two, "no + or -", fixed 32-bit width, subsets of a small set.

6. Four classic traps

Trap 1: negative numbers in Python never run out of 1s

Python integers have no fixed width. A negative number behaves as if it had endless 1s on the left. So while n: n &= n - 1 on -1 never stops.

while n:            # n = -1
    n &= n - 1      # -1, -2, -4, -8, -16, ... never 0
# measure.py
drop loop on -1 (no mask): first values [-1, -2, -4, -8, -16], still not 0 after 100 steps
drop loop on -1 & MASK: steps = 32
bin(-5) = '-0b101'   bin(-5 & MASK) = '0b11111111111111111111111111111011'
-1 >> 1 = -1

Fix: n &= 0xFFFFFFFF first. That gives the 32-bit pattern (-1 becomes 32 ones). Shifting right does not help: -1 >> 1 is still -1.

Trap 2: ~x is not "flip 32 switches"

In Python ~x equals -x - 1. It flips the endless row, so the result is negative.

~5 = -6   ~5 & MASK = 4294967290

Fix: when you mean "flip the 32 bits", write ~x & 0xFFFFFFFF (or x ^ 0xFFFFFFFF).

Trap 3: add without + loops forever on negatives

The carry loop from Template D, without the mask:

while b:
    a, b = a ^ b, (a & b) << 1   # -1 + 1: the carry walks left forever
# measure.py
add_buggy(-1, 1): carry still True after 100 rounds (carry = 1267650600228229401496703205376)
add_fixed(-1, 1) = (0, 32)   # (answer, rounds)
add_fixed(-2, -3) = (-5, 2)
without the convert-back step: (-2 + -3) & MASK = 4294967291

Fix: mask both values every round, so the carry falls off at bit 32. Then convert back: if the result is above 0x7FFFFFFF, subtract 1 << 32.

Trap 4: reversing bits but stopping when n hits 0

Reverse Bits needs all 32 positions. Stopping early loses the zeros that should move to the right end.

r = 0
while n:                       # wrong: stops early
    r = (r << 1) | (n & 1)
    n >>= 1
# measure.py
reverse_buggy(1) = 1   reverse_fixed(1) = 2147483648 (0b10000000000000000000000000000000)
reverse_buggy(6) = 3   reverse_fixed(6) = 1610612736

Fix: for _ in range(32): instead of while n:.

One more, for other languages: in C and Java, x & 1 == 0 means x & (1 == 0). Python binds & tighter, so there it works (4 & 1 == 0 is True). Brackets cost nothing: write (x & 1) == 0.

Rule to rememberIf a negative number can appear, mask with 0xFFFFFFFF going in and convert back coming out. Loop over exactly 32 positions when position matters.

7. Complexity: count the work

Say you need the number of 1s in every number from 0 to 1000 (the Counting Bits problem).

# == 7. measure.py: count ones for every n in 0..1000 ==
scan steps total = 32032   drop steps total = 4938   dp steps = 1000
Step 1: where 32032, 4938 and 1000 come from

Check all 32 positions: 1001 numbers x 32 checks = 32032. Always the same, whatever the numbers are.

Drop the lowest 1: one step per 1. The numbers 0 to 1000 hold 4938 ones in total, so 4938 steps.

Reuse the smaller answer: one line per number from 1 to 1000, so 1000 steps.

scan: (n + 1) x 32 O(32 n) = O(n), with a big constant drop: total number of 1s O(n log n) at most dp: n O(n)
Step 2: one number, and the hidden costs

For one 32-bit number, both ways are O(1): at most 32 steps. The drop loop is O(k), where k is the number of 1s.

The XOR fold is O(n) time and O(1) extra memory. The counting dict is also O(n) time, but O(n) memory: on [2, 7, 4, 7, 2] it stored 3 keys.

Hidden cost: Python ints can grow without limit, so an unmasked loop on a negative number never ends (trap 1). Python 3.10 and newer also has n.bit_count(); (44).bit_count() gives 3. In an interview, say you know it, then write the loop.

Subsets by mask: 2n masks, each read in n steps, so O(n x 2n). Fine for n up to about 20.

9. Your lesson's questions

Q1. What is 12 & 11? How many steps does the drop loop take on 255?

8, and 8 steps. 12 is 1100, 11 is 1011; only bit 3 is on in both. 11 is 12 - 1, so this is one drop step: the lowest 1 of 12 (worth 4) is gone. 255 has eight 1s, so eight steps. Printed by measure.py.

Q2. What does the XOR fold return for [5, 3, 5, 9, 3]?

9. The 5s cancel and the 3s cancel, whatever their order. measure.py prints 9.

Q3. In Python, what is -3 & 0xFFFFFFFF, and why would you want it?

4294967293. It is the 32-bit pattern of -3 (thirty 1s, then 01), read as a non-negative number. Now loops end: the drop loop takes 31 steps on it, while on plain -3 it would never stop. Both numbers are printed by measure.py; try -3 in the sandbox too.

Glossary: new words from this lesson

bit
One switch: 0 or 1.
binary
Writing a number with bits; each position is worth double the one to its right.
set bit
A bit that is 1.
least significant bit
The rightmost bit, worth 1; it is 1 for odd numbers.
AND, OR, XOR
Column rules: both 1, either 1, different.
shift
Slide every bit left (times 2 per place) or right (divide by 2, rounding down).
mask
A stencil number whose 1s pick the bits to read, set, clear or flip.
two's complement
How negatives are stored: flip every bit of x and add 1. -1 is all 1s.
XOR fold
acc ^= x over a list; pairs cancel, singles remain.
lowest set bit
The rightmost 1. n & (n - 1) removes it; n & -n keeps only it.
carry
The 1 that moves one column left when both columns are 1 during addition.

Recap: the pattern card in one minute

Idea: a number is a row of switches. Each operator works column by column with no carries, so one line can flip, test or cancel many switches.

Signals: "twice except one" with O(1) memory, count or test 1 bits, power of two, no + or -, reverse bits, fixed 32-bit range, subsets of a small set.

Templates: XOR fold acc ^= x. Drop loop n &= n - 1. Bit i: get (x >> i) & 1, set x | (1 << i), clear x & ~(1 << i), toggle x ^ (1 << i). All counts: bits[i] = bits[i >> 1] + (i & 1).

Cost: O(1) per 32-bit number; the drop loop is one step per 1 (3 steps for 44 against 32 checks). XOR fold: O(n) time, O(1) memory.

Traps: negatives in Python (mask with 0xFFFFFFFF, convert back above 0x7FFFFFFF), ~x is -x - 1, reverse loops need exactly 32 rounds, brackets around & in C and Java.
