Graph explorer

Type edges as pairs joined by a dash, separated by commas. Pick a start node, then run BFS, DFS or a topological sort and step through it.

These match patterns/graphs/measure.py: the ring gives BFS A B F C E D and DFS A B C D E F (12 checks each); two groups reaches only A B C; getting dressed sorts to under, socks, shirt, pants, tie, shoes, belt, coat. In the one-way cycle nothing has in-degree 0, so no order exists.
