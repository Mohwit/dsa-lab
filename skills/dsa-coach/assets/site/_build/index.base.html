How XP works

A problem solved alone earns its full value: easy 30, medium 60, hard 100. With hints it earns 60 percent, after reading the solution 25 percent. A pattern lesson earns 40, and each prediction you lock in before peeking earns 5. Honest outcomes level you up faster in the long run: the review schedule depends on them.

Pattern map

Every interview problem is a costume over a small set of patterns. Each tile opens its pattern lesson. Segments fill as you solve: teal alone, yellow with hints, orange after reading the solution.

How a day works

  1. Solve anywhere. Drop a file in problems/ (for example problems/two_sum.py) and solve it your way. Put the LeetCode number or title in the file name or a comment.
  2. Run /dsa-coach. Claude spots the new file, works out its pattern, moves it to problems/<pattern>/NNNN-name/, checks it against tests and builds its page: every approach, the mental map, and a step-through trace.
  3. Read the page for the approaches you did not use, and press the outcome button that matches how it went. That sets when it comes back for review.
  4. Or follow the plan: ask for today and get 2 or 3 problems with hints that open one at a time.
